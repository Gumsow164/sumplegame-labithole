# Simple Side Scroll Game

## 概要
学習を目的としたJavaScriptとHTML5 Canvasを使用して制作した横スクロールアクションゲームです。
移動・ジャンプ・敵との当たり判定・スコア・ゴールクリアまでを実装しています。

## 操作方法
- ← → または A D：移動  
- Space：ジャンプ  

## 使用技術
- HTML5 Canvas
- JavaScript（Vanilla JS）

## 実装機能
- 横スクロールカメラ
- 加速と慣性のある移動
- 可変ジャンプ
- 段差・穴ギミック
- 敵AI（巡回・踏みつけ）
- スコアシステム
- ゴール旗によるクリア判定
- パーティクル演出（砂ぼこり・死亡・クリア）

## 学習目的
- JavaScriptによるゲームループ設計
- 当たり判定処理の理解
- 状態遷移（タイトル/プレイ/ゲームオーバー/クリア）の実装練習
